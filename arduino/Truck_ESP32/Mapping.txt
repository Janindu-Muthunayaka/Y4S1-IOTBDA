Quick firmware notes:
- I2C bus is initialized as Wire.begin(21, 22).
- DHT11 is read from GPIO 4.
- Shock value is computed as: shockG = abs(totalG - 1.0).
- Alert threshold in code: SHOCK_THRESHOLD = 0.1.
- Button uses INPUT_PULLUP, so wiring is button-to-GND for press events.
